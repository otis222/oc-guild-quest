# 專屬小人：收件處部署和自動生成（T19）

> 給組員看的。玩家在網站的「專屬小人」送出自己的 OC 圖 → 存進你的 Google 雲端硬碟 → 你電腦上的自動生成程式把它交給 ComfyUI 做成小人 → 傳回雲端硬碟 → 玩家用領取碼領回去、換上。
> 網站本身不接 AI。只有收件處（你 Google 帳號裡的 Apps Script）會收到玩家按「送出」的那一張圖；生成只在你的電腦上做。

```
玩家的網站 ──送 OC 圖──▶ 收件處（Apps Script）──▶ 你的雲端硬碟 requests/
                              ▲          │
                        傳回小人 │          │ 拿 OC 圖
                              │          ▼
                    你電腦上的自動生成程式 ◀──▶ ComfyUI
```

要做的事：第一節（部署收件處）做一次；第二節（自動生成程式）第一次雙擊時照畫面設定，之後雙擊一次就會打開 ComfyUI、開始做小人。不想用自動生成程式，也可以照第三節手動做。

## 一、部署收件處（第一次，大約 10 分鐘）

1. 打開 <https://script.google.com>，用要收圖的 Google 帳號登入，按左上「新專案」。
2. 把 repo 裡 `tools/chibi-apps-script/Code.gs` 的內容整個貼進去，取代原本的 `function myFunction() {}`，按「儲存」（磁碟圖示）。左上的「未命名的專案」可以改名成「公會專屬小人收件處」。
   - 從 GitHub 複製：打開 repo 的 `tools/chibi-apps-script/Code.gs`，按右上「Copy raw file」（兩個方框的圖示）。
3. 設自動生成程式的鑰匙（要用第二節才需要，可以之後再回來設，不用重新部署）：左邊齒輪「專案設定」→ 拉到最下面「指令碼屬性」→「新增指令碼屬性」：
   - 屬性：`WORKER_KEY`
   - 值：自動生成程式第一次雙擊時，畫面上的那串（第二節第 3 步）

   按「儲存指令碼屬性」。鑰匙只存在這裡和你電腦的 `config.json`，不要寫進 Code.gs（repo 是公開的）。
4. （可以不做）想擋陌生人：把 `const INVITE_CODE = '';` 改成一組邀請碼，例如 `const INVITE_CODE = 'guild29';`，再把邀請碼告訴玩家。玩家第一次送出時網站會叫她填。邀請碼只改在 script.google.com 這一份，不要改回 repo。
5. 右上「部署」→「新增部署作業」→ 左邊「選取類型」的齒輪 →「網頁應用程式」：
   - 說明：隨便寫，例如「第一版」
   - 執行身分（Execute as）：我（你的帳號）
   - 誰可以存取（Who has access）：所有人（Anyone）。不是「所有擁有 Google 帳戶的使用者」。

   按「部署」。第一次會要你授權：「授予存取權」→ 選帳號 → 看到「Google 尚未驗證這個應用程式」按「進階」→「前往 公會專屬小人收件處（不安全）」→「允許」。這是你自己的程式，Google 沒審查過才會這樣提醒。
6. 複製「網頁應用程式」的網址（`https://script.google.com/macros/s/……/exec`）。用**無痕視窗**打開，看到 `{"ok":true,"name":"oc-guild-quest 專屬小人"}` 就表示部署好了，而且沒登入的人也連得到。
7. 把網址告訴 Claude，或自己在 repo 根目錄新增 `.env.production`，寫一行（換成你的網址）：

   ```
   VITE_CHIBI_ENDPOINT=https://script.google.com/macros/s/……/exec
   ```

   commit、push。合併到 main 自動部署以後，OC 設定卡才會出現「專屬小人」。沒有這行就不會出現，網站其他功能照舊。
   - Playtest 期間（10/14～10/20）不合併。在那之前想先試，見第四節。
   - 這個網址會寫進網站的程式，看得到網頁原始碼的人都找得到。知道網址只能送圖（一天最多 30 張）；沒有鑰匙看不到別人的 OC，也不能放小人。
8. 之後改了 Code.gs：「部署」→「管理部署作業」→ 鉛筆「編輯」→「版本」選「新版本」→「部署」。網址不會變。只改指令碼屬性不用重新部署。

## 二、自動生成：你的電腦開著 ComfyUI 就會自己做

程式在 `tools/chibi-worker/`。它每 30 秒問收件處一次：有新的 OC 就下載、交給 ComfyUI、把做好的小人傳回收件處，玩家按「看看好了沒」就領得到。玩家領走以後，這台電腦上的那份也會刪掉。

### 第一次：雙擊，照畫面回答（大約 5 分鐘）

1. 裝 Node.js 18 以上：<https://nodejs.org> 下載 LTS 版，一直按下一步。不用裝別的套件。
2. 把 repo 放到你的電腦：`git clone https://github.com/otis222/oc-guild-quest.git`，或在 GitHub 按「Code → Download ZIP」解壓縮。
3. 雙擊 `tools/chibi-worker/start-windows.bat`（Mac：`start-mac.command`，第一次要按右鍵 →「打開」）。視窗會一步一步問：
   1. **收件處網址**：貼上第一節拿到的 `/exec` 網址（Windows 的視窗按右鍵就是貼上）。程式會連連看。
   2. **鑰匙**：畫面上會有一串鑰匙。照第一節第 3 步存成 Apps Script 的指令碼屬性 `WORKER_KEY`，回來按 Enter，程式會確認對不對。
   3. **ComfyUI**：要它幫你打開 ComfyUI 的話，把啟動檔拖進視窗（免安裝版是 `run_nvidia_gpu.bat`；ComfyUI Desktop 拖桌面上的捷徑）。都自己開就直接按 Enter。ComfyUI 用 8188 還是 8000（ComfyUI Desktop），程式會自己找。
   4. **workflow**：在 ComfyUI 打開做小人的 workflow，選「Workflow → Export (API)」匯出（舊版 ComfyUI：設定裡打開 Dev mode，再按「Save (API Format)」），把匯出的檔案拖進視窗。有好幾個 Load Image 或 Save Image，它會列出來問你用哪一個。
   5. **模式**：畫好直接送給玩家，或先畫 3 張給你挑（見下面「兩種模式」）。
   6. **試畫一張**（可以跳過）：把一張 OC 圖拖進視窗，畫好會自己打開給你看。

   每一步做完就存好；中途關掉視窗，下次雙擊會接著問。設定好就直接開始做小人。
   - 設定存在 `tools/chibi-worker/config.json`。裡面有鑰匙，已經設定成不會上傳到 GitHub，也不要傳給別人。鑰匙外流的話：刪掉 `config.json` 再雙擊，會產生新的鑰匙，指令碼屬性也換成新的。

workflow 要：
- 有一個 **Load Image** 節點放 OC 圖，程式每次會換成玩家的圖。
- 最後有 **Save Image** 節點，程式把它的圖送給玩家。輸出盡量跟 `public/sprites/` 裡的小人一樣：全身、正面、腳在最下面，背景透明最好（白底也可以，網站會自動去背）。
- 提示詞照 workflow 裡寫的；種子（seed）每次會換新的，同一張 OC 重畫才會不一樣。
- 玩家寫的「給組員的話」不會自動放進提示詞（多半是中文），會印在畫面上，也寫在 `jobs/領取碼/info.txt`。需要照她的話改，就用挑選模式自己看過再送。

### 每天用：雙擊一次

1. 雙擊 `start-windows.bat`（Mac：`start-mac.command`）。ComfyUI 還沒開，它會幫你打開（第三步有拖啟動檔的話），接著檢查一遍、開始做小人。
   - 放到桌面比較好找：對 `start-windows.bat` 按右鍵 →「傳送到」→「桌面（建立捷徑）」。
2. 視窗開著就會一直做；關掉視窗就停。畫面會寫收到誰的 OC、給你的話、什麼時候送出。ComfyUI 被關掉或網路斷了，它會等，好了自己繼續。
3. 不要在視窗裡點一下：Windows 會進入「選取」模式，程式會停住，按 Esc 就繼續。
4. 你在 ComfyUI 做別的事也可以，玩家的 OC 會排在後面。不要同時開兩個，第二個會說「已經有一個在跑」。
5. 想改設定（換網址、換 workflow、換模式、換 ComfyUI 啟動檔）：先關掉正在跑的視窗，再雙擊 `setup-windows.bat`（Mac：`setup-mac.command`）。每一步都可以直接按 Enter 不改，設好就開始。改了 workflow 也要這樣重新拖一次。

### 用終端機的話

在 repo 資料夾執行（Mac、Linux 都一樣）：

| 指令 | 做什麼 |
| --- | --- |
| `node tools/chibi-worker/worker.mjs` | 跟雙擊 start 一樣 |
| `node tools/chibi-worker/worker.mjs --setup` | 跟雙擊 setup 一樣 |
| `node tools/chibi-worker/worker.mjs --check` | 只檢查設定、workflow、ComfyUI、收件處，四項打勾就好了 |
| `node tools/chibi-worker/worker.mjs --try 你的OC圖.png` | 用一張圖試畫，不連收件處，畫好的在 `jobs/_try/` |
| `node tools/chibi-worker/worker.mjs --once` | 跑一輪就結束 |

### 兩種模式

- **自動模式**（預設）：畫好一張就送出，玩家最快拿到。
- **挑選模式**：設定第五步選 2（或 `config.json` 寫 `"review": true`）。每個 OC 畫 `candidates` 張（預設 3 張），放在 `tools/chibi-worker/jobs/領取碼/`，叫 `1.png`、`2.png`…，旁邊的 `oc.png` 是玩家的原圖。
  - 喜歡哪張，就把它**改名成 `ok.png`**，下一輪（30 秒內）送出。
  - 不喜歡的刪掉，會補畫到 3 張。

### 想重畫已經送出的小人

玩家還沒領的話：到雲端硬碟「oc-guild-quest 專屬小人 / results」把那張刪掉，程式下一輪會重畫、重送。玩家已經領走的話，請她在網站按「再訂一隻」。

### 檔案在哪裡、什麼時候刪

| 地方 | 放什麼 | 什麼時候刪 |
| --- | --- | --- |
| 雲端硬碟 `requests/`、`results/` | 玩家的 OC 圖、`.txt`、小人 | 玩家領走或換一張重送時，收件處自動丟進垃圾桶 |
| `tools/chibi-worker/jobs/領取碼/` | 下載的 OC 圖、`info.txt`、畫好的小人 | 玩家領走或取消後，程式自動刪掉 |
| ComfyUI 的 `input/oc-guild-quest/`、`output/oc-guild-quest/` | ComfyUI 自己留的輸入和輸出 | 不會自動刪，偶爾自己清 |

簡報要用的話，在玩家領走前把 `jobs/` 裡的資料夾複製出去。

### config.json 裡有什麼

雙擊設定時都會幫你填好，一般不用自己改。

| 設定 | 預設 | 說明 |
| --- | --- | --- |
| `inboxUrl` | （設定時填） | 收件處網址，/exec 結尾 |
| `workerKey` | （自動產生） | 跟指令碼屬性 `WORKER_KEY` 一樣 |
| `comfyUrl` | `http://127.0.0.1:8188` | ComfyUI 的網址。找不到時會自己試 `http://127.0.0.1:8000`（ComfyUI Desktop），找到就改好 |
| `comfyStart` | （設定時填） | 啟動 ComfyUI 的檔案，ComfyUI 沒開時幫你打開；`""` 是你自己開 |
| `workflow` | `workflow_api.json` | Export (API) 存的檔案，位置相對於 `config.json` |
| `review` | `false` | `true` 是挑選模式 |
| `candidates` | `3` | 挑選模式每個 OC 畫幾張（1～8） |
| `imageNode` | （設定時選） | 有好幾個 Load Image 時，放 OC 圖的那個（節點編號或標題） |
| `outputNode` | （設定時選） | 有好幾個 Save Image 時，要送出的那個（沒填就用編號最大的） |
| `pollSeconds` | `30` | 幾秒問一次收件處（10～3600） |
| `timeoutMinutes` | `20` | 一張最多等幾分鐘（1～180）。超過了下一輪接著等 |

JSON 的小規則：字串要用 `""` 包起來；`true`、`false`、數字不加引號；最後一項後面不能有逗號；路徑用 `/`。

### 看到這些字的時候

| 畫面上的字 | 怎麼辦 |
| --- | --- |
| Apps Script 還沒設鑰匙 | 第一節第 3 步 |
| 鑰匙對不上 | 指令碼屬性的 `WORKER_KEY` 和 `config.json` 的 `workerKey` 要一模一樣 |
| 收件處還是舊版的程式 | 貼上新的 Code.gs，「管理部署作業 → 編輯 → 新版本 → 部署」 |
| 收件處回的不是 JSON | 網址要 /exec 結尾；「誰可以存取」要選「所有人」 |
| 連不上 ComfyUI | 開 ComfyUI；網址不對就雙擊 setup 重新設定 |
| 打不開 ComfyUI | 啟動檔搬家了：雙擊 setup，第三步重新拖一次 |
| ComfyUI 不接受這個 workflow | 後面會寫哪個節點錯（模型找不到、缺節點…），在 ComfyUI 修好再匯出一次 |
| 做不出來 | 照後面寫的原因修好，重新執行程式會再試一次 |
| 已經有一個自動生成程式在跑 | 開了兩個，關掉一個（改了設定的話，關掉正在跑的再重開）。確定只有一個的話，刪掉 `jobs/.lock` |

## 三、不開自動生成程式：手動做

1. 雲端硬碟最上層會有一個資料夾「oc-guild-quest 專屬小人」，第一張圖送進來時自動建好，裡面有兩個資料夾：
   - `requests`：玩家送來的 OC 圖，檔名是領取碼（例：`K7Q2-M9X.png`）。旁邊同名的 `.txt` 寫著 OC 名字、玩家給你的話、送出時間。
   - `results`：做好的小人放這裡。

   裝了「Google 雲端硬碟電腦版」的話，可以直接在電腦的資料夾裡拿，不用下載。
2. 在你的電腦用 ComfyUI 做成小人，格式跟第二節第 5 步一樣（高度 360px 以上就好，網站會裁掉空白、縮成高 360px）。
3. 存成「領取碼.png」（例：`K7Q2-M9X.png`），放進 `results`。JPG、WebP 也認得，但 JPG 沒有透明背景。
4. 跟玩家說做好了。她在設定卡按「專屬小人」→「看看好了沒」就會領到，可以「換上這隻」或「先收著」。
5. 玩家領走時，收件處會把 `requests` 和 `results` 裡這個領取碼的檔案丟進雲端硬碟的垃圾桶。你電腦上的輸入、輸出請自己刪掉。

手動和自動可以一起用：自動生成程式只做 `results` 裡還沒有小人的 OC。

## 四、上線前先試（Playtest 結束前不合併）

- **收件處**：用無痕視窗打開網址，看到 `{"ok":true,…}`。
- **收件處 + 自動生成程式 + ComfyUI**：雙擊 start 以後，「檢查」的四項打勾。再把任一張 PNG 改名成 `TEST-AAA.png`（任何「4 碼-3 碼」都可以，別用 0、O、1、I、L），放進雲端硬碟的 `requests/`。自動生成程式會做好放進 `results/`。試完把兩邊的 `TEST-AAA` 刪掉，程式也會刪掉自己那份。
- **連網站一起試**：在 repo 根目錄新增 `.env.local`（不要 commit），寫 `VITE_CHIBI_ENDPOINT=你的網址`，執行 `npm install`、`npm run dev`，用電腦打開 <http://localhost:5173>。接一張委託，每個任務按「開始」再按「提早完成」，做完 5 個就能訂一隻。

## 五、要注意的

- **只有玩家按「送出」的那一張 OC 圖會離開她的瀏覽器。** 作業照片、進度、事件紀錄都不會上傳。送出前網站會寫清楚圖會傳到哪裡。
- B 說過看到 AI 幾秒鐘就生出細節很多的圖會焦慮（企劃表 B｜L114）。專屬小人是可以不用的獎勵，請先問她願不願意。
- 收件處的上限在 Code.gs 開頭可以改：一天最多 30 張（`MAX_PER_DAY`），一張最大 8MB（`MAX_BYTES`）。ComfyUI 的輸出超過 8MB 時，自動生成程式會改傳 WebP。
- 不做小人的時候，把自動生成程式關掉就好；玩家送的圖會在雲端等你。
- 玩家看到這些字的時候：
  - 「收件處要邀請碼，請跟組員要。」：Code.gs 有設 `INVITE_CODE`，她還沒填或填錯。
  - 「連不上收件處，檢查網路再按一次。」：沒網路，或部署時「誰可以存取」不是「所有人」。
  - 「收件處出問題了，晚點再試。」：通常是 Apps Script 執行時出錯。到 script.google.com 的專案 →「執行項目」看紀錄。
  - 「今天收太多張了，明天再試。」：一天超過 `MAX_PER_DAY` 張。
