# 專屬小人：收件處設定和製作流程（T19）

> 給組員看的。玩家在網站的「專屬小人」送出自己的 OC 圖 → 存進你的 Google 雲端硬碟 → 你在自己的電腦用 ComfyUI 做成小人 → 放回雲端硬碟 → 玩家用領取碼領回去、換上。
> 網站本身不接 AI，也不存在別的地方；只有收件處（你 Google 帳號裡的 Apps Script）會收到玩家按「送出」的那一張圖。

## 一、第一次設定（大約 10 分鐘）

1. 打開 <https://script.google.com>，用要收圖的 Google 帳號登入，按「新專案」。
2. 把 repo 裡 `tools/chibi-apps-script/Code.gs` 的內容整個貼進去，取代原本的 `function myFunction() {}`，存檔。專案名稱可以取「公會專屬小人收件處」。
3. （可以不做）想擋陌生人：把 `const INVITE_CODE = '';` 改成一組邀請碼，例如 `const INVITE_CODE = 'guild29';`，再把邀請碼告訴玩家。玩家第一次送出時網站會叫她填。邀請碼只改在 script.google.com 這一份，不要改回 repo（repo 是公開的）。
4. 右上「部署」→「新增部署作業」→ 左邊的齒輪選「網頁應用程式」：
   - 執行身分（Execute as）：我（你的帳號）
   - 誰可以存取（Who has access）：所有人（Anyone）

   按「部署」。第一次會要你授權存取雲端硬碟：選帳號 →「進階」→「前往〔專案名稱〕（不安全）」→「允許」。這是你自己的程式，Google 沒審查過才會這樣提醒。
5. 複製「網頁應用程式」的網址（`https://script.google.com/macros/s/……/exec`）。
6. 在 repo 根目錄新增 `.env.production`，寫一行（換成你的網址）：

   ```
   VITE_CHIBI_ENDPOINT=https://script.google.com/macros/s/……/exec
   ```

   commit、push。合併到 main 自動部署以後，OC 設定卡才會出現「專屬小人」。沒有這行就不會出現，網站其他功能照舊。
   - 想先在自己的電腦試：把同一行寫在 `.env.local`（不要 commit），再 `npm run dev`。
   - 這個網址會寫進網站的程式，看得到網頁原始碼的人都找得到。邀請碼和「一天最多 30 張」就是用來擋惡作劇的。
7. 之後改了 Code.gs：「部署」→「管理部署作業」→ 鉛筆圖示 →「版本」選「新版本」→「部署」。網址不會變。

## 二、玩家送出以後

1. 雲端硬碟最上層會有一個資料夾「oc-guild-quest 專屬小人」，第一張圖送進來時自動建好，裡面有兩個資料夾：
   - `requests`：玩家送來的 OC 圖，檔名是領取碼（例：`K7Q2-M9X.png`）。旁邊同名的 `.txt` 寫著 OC 名字、玩家給你的話、送出時間。
   - `results`：你做好的小人放這裡。

   裝了「Google 雲端硬碟電腦版」的話，可以直接在電腦的資料夾裡拿，不用下載。
2. 在你的電腦用 ComfyUI（oc-chibi-tool）把 OC 圖做成小人。輸出盡量跟 `public/sprites/` 裡的小人一樣：
   - 全身、正面、腳在最下面
   - 背景透明的 PNG 最好；白底也可以，網站會自動去背
   - 高度 360px 以上就好，網站會裁掉空白、縮成高 360px
3. 存成「領取碼.png」（例：`K7Q2-M9X.png`），放進 `results`。JPG、WebP 也認得，但 JPG 沒有透明背景。
4. 跟玩家說做好了。她在設定卡按「專屬小人」→「看看好了沒」就會領到，可以「換上這隻」或「先收著」。
5. 玩家領走時，網站會請收件處把 `requests` 和 `results` 裡這個領取碼的檔案（圖和 `.txt`）丟進雲端硬碟的垃圾桶。你電腦上 ComfyUI 的輸入、輸出也請自己刪掉。

做不好想重做：把新的圖用同一個檔名放進 `results`（蓋掉舊的）。如果玩家已經領過，請她在網站按「再訂一隻」重送一次。

## 三、要注意的

- **只有玩家按「送出」的那一張 OC 圖會離開她的瀏覽器。** 作業照片、進度、事件紀錄都不會上傳。送出前網站會寫清楚圖會傳到哪裡。
- B 說過看到 AI 幾秒鐘就生出細節很多的圖會焦慮（企劃表 B｜L114）。專屬小人是可以不用的獎勵，請先問她願不願意。
- 收件處的上限在 Code.gs 開頭可以改：一天最多 30 張（`MAX_PER_DAY`），一張最大 8MB（`MAX_BYTES`）。
- 玩家看到這些字的時候：
  - 「收件處要邀請碼，請跟組員要。」：Code.gs 有設 `INVITE_CODE`，她還沒填或填錯。
  - 「連不上收件處，檢查網路再按一次。」：沒網路，或部署時「誰可以存取」不是「所有人」。
  - 「收件處出問題了，晚點再試。」：通常是 Apps Script 執行時出錯。到 script.google.com 的專案 →「執行項目」看紀錄。
  - 「今天收太多張了，明天再試。」：一天超過 `MAX_PER_DAY` 張。
